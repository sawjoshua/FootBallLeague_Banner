Match control

Set up the teams and match details. Your changes update the live preview automatically.

MATCH TIMER

Choose a starting time, then use Start, Pause, or Reset to control the on-screen match clock.

The match clock runs while this page is open. It is not tied to your computer’s real-world clock.

Use +1 after a goal, or type a score directly. The goal graphics below also add one to the selected team.

PLAYER & MATCH GRAPHICS

Fill in these details first, then choose a graphic. For a substitution, enter the player coming on and write “OFF: player name” in the detail.

Goal buttons add 1 to that team and show the goal graphic. Event graphics appear with the scoreboard; use the visibility buttons to hide individual items.
APPEARANCE & OBS OUTPUT

Transparent is recommended for OBS. Use a colored background only if you plan to add a Chroma Key filter.

Add the graphics to OBS
  1. In a terminal opened in the project folder, run python3 touchline_server.py. Leave the terminal open.
  2. In OBS, add a Browser Source to your scene.
  3. Click Copy OBS link, then paste the link into the source URL.
  4. Set the source size to 1920 × 1080. Keep the background transparent.

Keep this control page open while you operate the match. Choose green or blue only if you want to use an OBS Chroma Key filter.
